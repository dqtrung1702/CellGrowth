# BA Intake And Project Framing

File nay la diem bat dau khi agent duoc giao tai lieu BA de xay dung mot du an moi.

## Muc tieu

- Chuyen tai lieu BA thanh input ky thuat ro rang.
- Tach requirement that, assumption, constraint, va open question.
- Chot scope MVP truoc khi thiet ke kien truc va viet code.

## Dau vao mong doi

- BRD, PRD, SRS, user story, BPMN, mockup, wireframe, spreadsheet, meeting note, hoac file mo ta nghiep vu.
- Rang buoc ve ngan sach, deadline, stack, security, compliance, deployment, hoac he thong can tich hop.

## Dau ra bat buoc

1. Product summary
2. Business goal
3. Actor va role
4. Use case list
5. Business rule list
6. Functional requirement list
7. Non-functional requirement list
8. Data object list
9. Integration list
10. Open question list
11. Assumption list
12. MVP scope
13. Out-of-scope list

## Cach doc tai lieu BA

### 1. Chot muc tieu kinh doanh

Tra loi:

- He thong sinh ra de giai quyet van de gi?
- KPI thanh cong la gi?
- Ai la nguoi su dung chinh?
- Gia tri lon nhat cua MVP la gi?

### 2. Liet ke actor va permission

Moi actor can co:

- ten role
- muc tieu
- hanh dong duoc phep
- du lieu duoc nhin va duoc sua
- dieu kien han che

### 3. Liet ke use case

Moi use case can co:

- trigger
- input
- precondition
- happy path
- alternative path
- error path
- output
- acceptance criteria

### 4. Tach business rule

Business rule nen viet duoi dang phat bieu co the test:

- neu dieu kien A thi hanh dong B
- doi tuong X chi duoc lam Y khi Z
- he thong phai tinh theo cong thuc R

### 5. Tach NFR

Can doc ro:

- security
- audit
- performance
- scale
- availability
- privacy
- localization
- accessibility
- observability
- data retention

### 6. Xac dinh open question

Neu BA doc chua ro, agent phai ghi ro:

- truong hop nghiep vu con mo
- conflict giua hai requirement
- du lieu dau vao chua du
- stack chua chot
- integration chua co contract

## Quy tac

1. Khong nhay vao code khi BA scope chua du ro cho MVP.
2. Khong tu bo sung business rule moi neu chua danh dau la assumption.
3. Moi assumption phai duoc viet ro va theo doi den khi duoc xac nhan.
4. Neu BA doc yeu, agent van phai tao duoc requirement map tam thoi thay vi mo ho.
